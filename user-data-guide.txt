EAM DATABASE SEED GUIDE - USERS TABLE
================================================================================

This file contains guides and raw SQL / JSON data for populating the "User" table
with all possible roles as per the database schema.

The system uses four main roles:
1. ADMIN      - Full configuration, settings, dashboard, and strategic targets.
2. MANAGER    - Operations, asset review, inventory planning, work orders.
3. TECHNICIAN - Receives work orders, creates parts requests.
4. VIEWER     - Read-only dashboard and asset history analytics.
